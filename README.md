**Coin Catcher** — a complete 2D Roblox game built for make.fun's "Make the best Roblox game" bounty. Coins fall from the sky; slide the basket to catch them. Star coins are worth 25, bombs cost a life. 60 seconds, 3 lives, levels that speed up every 15 seconds, and a Play Again loop. Fully client-side Luau on a ScreenGui — arrow keys / A D on desktop, finger-drag or hold the on-screen &lt; &gt; buttons on mobile.

## Run it

```sh
rojo build default.project.json --output game.rbxl
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
